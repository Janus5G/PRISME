Kapacitet per glimt

Niv.TilstandeBitNyttelast
Fire niveauer per kanal rammer 4⁴ = 256 på de synlige kanaler alene. Hele tegnsættet i ét glimt, og UV står fri til kontrol. Hver fordobling af niveauer koster cirka 6 dB signal-støj-forhold og giver kun 2 bit tilbage.

Instruktionssæt 16 operationer

R·GInstruktionVirkning
Opkoden deler sig i fire kanaler: R klasse, G operation, B destination, V kilde. Afkoderen kan begynde på rød kanal alene. Registre er A B C D. Hukommelsen er 256 bytes — nøjagtig ét glimt bredt.

Nulflaget sættes af aritmetik, CMP, MOV og LOAD. SET rører det ikke.
